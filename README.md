# 视频预览图 · Eagle 插件

在 Eagle 检查器里，把视频按等距时间点抽成**静态预览图网格**，一眼扫完这个视频的大致内容。

支持 mp4 / mov / m4v / webm / mkv / avi / flv / wmv。开源地址：https://github.com/Dugege007/eagle-video-preview-grid

## 一、插件功能

- **静态预览图 + 时间码**：每张图下标注 `MM:SS` / `HH:MM:SS`，纯图片，不加载视频播放器。
- **数量按时长自动**：未手动设置过的视频按视频时长自动选 **3–30 张**（分桶表见第四节），不再是固定 9 张；手动改过数量后按视频各自记住，范围 0–30。设为 **0** 表示该视频不生成预览图。
- **右键设为封面**：在任意成功生成的预览图上右键 →「设为封面」，把该帧设为 Eagle 中该素材的封面。
- **自动生成**：可选开关（默认关闭），开启后每次选中视频自动生成；已有符合规则的预览图直接复用，不重复抽帧。
- **清空**：删除该视频所有规格的预览图，并把数量恢复为「按时长自动」。
- **切换数量可对比**：改数量重新生成后，旧数量的预览图不会立刻删除，切回去直接复用、不重抽；用不到的规格在下次启动插件时清理。
- **展开 / 折叠**：超过 9 张时可展开看全部，收起显示前 9 张；网格高度随张数变化（0 张时不占高度）。
- **主题适配**：跟随 Eagle 的 6 套主题配色。
- 缩图缓存放在 Eagle 用户数据目录；除「设为封面」外不写入资源库；换机或迁移后自动重建。

## 二、安装

1. 在 Eagle 插件中心安装官方 **「FFmpeg 依赖插件」**（必需）。
2. 把插件目录放进 Eagle 插件目录：
   - Windows：`C:\Users\[用户名]\AppData\Roaming\Eagle\Plugins\`
   - 入口：Eagle →「插件」→「开发者选项」→「打开插件文件夹」
3. 重启 Eagle，选中一个视频，右侧检查器出现「视频预览图」区块（首次可拖动区块调整位置）。

要求：Eagle 4.0 build22 或更高；Windows 优先（FFmpeg 依赖插件在 Windows 已验证）。

## 三、使用

| 操作 | 结果 |
| --- | --- |
| 点「生成」 | 按该视频的数量抽帧；自动模式下先按时长算出张数 |
| 开启「自动生成」 | 隐藏「生成 / 清空」按钮；之后每次选中视频自动生成（开启当下不立即生成） |
| 改「数量」并确认（失焦 / 回车） | 退出自动模式、按视频记住；自动生成开启时立即刷新，关闭时提示点「生成」 |
| 数量改为「0」 | 立即清除该视频已有预览图，网格高度归 0，不抽帧；「自动生成」开启时也不会再为它生成 |
| 数量从 0 改回 1–30 | 立即恢复生成（自动生成开启时）或提示点「生成」 |
| 点「清空」（红色） | 删除该视频所有规格的预览图，网格高度归 0，并把数量恢复为「按时长自动」 |
| 右键某张预览图 | 弹出菜单「设为封面」；该帧会成为 Eagle 中此素材的封面 |
| 切换数量后切回去 | 旧数量的预览图仍在缓存中，直接复用、不重新抽帧 |
| 超过 9 张 | 出现「展开 / 收起」 |

开关状态与展开状态是全局的；生成数量按视频各自保存（自动 / 手动）。

## 四、插件算法

设视频时长 `T` 秒、生成数量 `N`（未手动设置时按下方分桶表按时长自动决定，范围 0–30），最低间隔 5 秒。`N = 0` 时直接返回空结果，不读取时长、不调用 FFmpeg：

```
gap = max(T / (N + 1), 5)
M   = min(N, floor(T / gap))
t_i = T - M·gap + (i - 1)·gap      (i = 1 … M)
```

即把视频分成 `N+1` 段、去掉首尾，取中间各连接处的帧；**从尾部往前对齐**，尾部保留完整段，首部不足 5 秒的余段截断。

| 时长 | 数量 | 实际张数 | 时间点 |
| --- | --- | --- | --- |
| 100s | 9 | 9 | 10, 20, …, 90 |
| 28s | 9 | 5 | **3, 8, 13, 18, 23** |
| 12s | 9 | 2 | 2, 7 |
| 4s | 9 | 0 | 不足 5 秒，不生成 |
| 任意 | **0** | 0 | 设为 0，不生成 |

**按时长自动分桶**（每档 +3 张，边界凑整、非线性递增；`< 30s` 的「3 张及以下」由 5 秒最低间隔自动保证）：

| 时长 | 张数 | 时长 | 张数 |
| --- | --- | --- | --- |
| < 30s | 3 | 10–20min | 18 |
| 30s–1min | 6 | 20–40min | 21 |
| 1–2min | 9 | 40–60min | 24 |
| 2–5min | 12 | 60–120min | 27 |
| 5–10min | 15 | ≥ 120min | 30 |

首点若落在 0 秒（片头黑帧）会跳过最靠首的一段。抽帧由 FFmpeg 完成（`-ss` 前置快速 seek + `-accurate_seek`），输出 192px 宽 JPEG，单张失败不影响其他卡片。

## 五、注意事项

- **依赖 FFmpeg 插件**：未安装时无法取时长与抽帧。
- **设为封面会写入资源库**：这是本插件唯一会改动素材的操作（调用官方 `item.setCustomThumbnail`）。缩图会先复制一份到 `covers/`，清理缓存不影响已设置的封面。除此之外预览图仍是派生缓存，不写 `metadata.json`、不随 Eaglepack 迁移。
- **数量设置存本地缓存**：自动 / 手动标记按视频保存，不随资源库迁移；换机或新资源库里的视频会重新按时长自动决定张数。设为 0 是显式手动设置，需手动改回 1–30 才恢复。
- **切换数量与缓存清理**：每个数量各存一套 `n<数量>/` 缓存，改数量不会立刻删旧的，切回去直接复用；用不到的规格在**下次启动 Eagle、插件加载时**自动清理（官方没有「主程序退出」事件，无法在关闭瞬间执行）。升级前的旧缓存视为 9 张那套，直接兼容、不需重抽。
- **自动模式需要时长**：已有缓存的视频直接从缓存读时长；没有任何缓存的视频会先跑一次 `ffprobe` 取时长，切换时可能多一点延迟。手动改过数量的视频不再自动变化。
- **抽帧失败的点**：会保留在原时间点上显示「抽帧失败」占位卡片（仍算 9 张里的一张），可据此判断视频哪个区段可能损坏、是否需要重新下载资源。成功与失败的结果会一起缓存，不会反复重抽；想重试请点「清空」或改一次数量。
- **抽帧中途切换**：每抽完一帧就落盘，切回来只补没抽完的帧、不从头开始；未抽完的显示「待抽帧」。后台任务不主动中断。
- **官方能力边界**：点击预览图**不能**让 Eagle 主播放器跳到该时间点（Plugin API 没有 seek / time 参数）；检查器区块外框高度由 Eagle 固定，插件只能调整自身预览图区域的高度。需要跳转请继续用 Eagle 原生影片笔记。
- **开发时用目录联接安装的**：不要在 Eagle 界面里点本插件的「卸载 / 删除」，也不要对链接用 `Remove-Item -Recurse` / `rm -rf`（会穿透链接删到源码）。安全移除用 `[System.IO.Directory]::Delete("链接路径")`。
- 预览图用于「内容总览」，不是精确选帧工具；时间点由算法确定性计算，不跟随原生笔记。
